2. Gegenstand dieser Erklärung

Diese Datenschutzerklärung informiert über die Verarbeitung personenbezogener Daten bei der Nutzung des Android-Spiels „Döner Tycoon“. Je nach installierter Version können bestimmte nachfolgend beschriebene Funktionen noch nicht verfügbar sein.

3. Spielstände und lokale Daten

Das Spiel speichert Spielfortschritt und Einstellungen lokal auf dem Gerät. Hierzu können unter anderem Spielgeld, Mitarbeiter, Upgrades, Meilensteine, Spracheinstellungen und Zeitangaben für Offline-Einnahmen gehören. Diese Daten werden für die Spielfunktion benötigt. Eine Übertragung dieser lokalen Spielstände an einen eigenen Server des Entwicklers ist derzeit nicht vorgesehen. Bei einer Deinstallation können lokal gespeicherte Daten verloren gehen; geräte- oder plattformseitige Sicherungsfunktionen können hiervon abweichen.

Das Spiel ist für freiwillige Werbevideos mit Belohnung („Rewarded Ads“) vorgesehen. Eine Anzeige wird nur auf ausdrückliche Aktion des Spielers gestartet. Zur Bereitstellung und Messung von Werbung kann das Google Mobile Ads SDK technische Informationen verarbeiten, etwa IP-Adresse, Geräteinformationen, Werbe-ID (soweit verfügbar und zulässig), Nutzungs- und Interaktionsdaten. Abhängig von den Einstellungen können Daten an Google und beteiligte Werbepartner übermittelt werden.
